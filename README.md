# Self-Driving Car AI Simulation

## Overview
Developed an **interactive self-driving car simulation** utilizing a **fully connected feedforward neural network** for decision-making. Cars perceive the road using a **sensor-based model** for obstacle detection and path planning, while a **real-time visualizer** illustrates neural network processing and decisions. Users can switch between **AI-driven** and **manual control** modes, providing flexible interaction and experimentation.

**Key Highlights:**
- AI-driven autonomous cars learn to navigate traffic and optimize performance.
- Manual mode allows users to control a car with keyboard inputs.
- Real-time visualizer demonstrates neural network outputs and decision-making.

## Educational Purpose
This project is designed for **learning and experimentation**, demonstrating:  
- Neural network decision-making in real-time  
- Sensor-driven autonomous control systems  
- AI adaptation and evolution through mutation and performance feedback  

## Features
- AI and manual driving modes with seamless toggling  
- Dynamic traffic and realistic road physics  
- Sensor visualization for obstacle detection  
- Real-time neural network visualization  
- Persistent learning: best-performing AI “brains” saved locally  
  
## Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript  
- **Visualization:** Canvas API  
- **AI:** Fully connected feedforward neural network implemented in JavaScript
